MARKET INTEL STUDIO - COPY-PASTE EDITION
No API key. No server. No setup.

HOW TO OPEN
1. Unzip this folder.
2. Double-click "Market-Intel-Studio-Copy-Paste.html" (opens in Chrome).

HOW IT WORKS
At every step the tool shows a prompt.
1. Click "Copy prompt".
2. Paste it into a NEW chat on Gemini, ChatGPT or Claude. Turn web search on when the box says so.
3. Copy the WHOLE reply and paste it into the second box in the tool.
4. Click "Use this reply".

STEPS (about 5 to 8 rounds in total)
1. Your business      - 1 round
2. Competitors        - 1 round (add or remove competitors afterwards)
3. Ad insights        - 1 round for all competitors, then 1 round to build 12+ ideas
4. Creatives          - 1 round per idea you tick (5 to 8 concepts each)

TIPS
- If a reply is cut off, type "continue" in the chat, then copy the full text again.
- If the tool cannot read a reply, ask the chat: "send only the JSON", then paste that.
- Screenshots of competitor ads: tick the screenshot box on that competitor, attach the
  files in the chat, and name each file starting with the competitor's name.
- Gemini or ChatGPT with web search gives the best competitor research.
- Research saves in your browser. Use the History button to come back to it.

SHARING
Send the same HTML file to teammates. Each person's research stays in their own browser.
To put it online, upload it to any static host and rename it to index.html.
